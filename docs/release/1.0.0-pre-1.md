## 接受范围

本次预发布可以接受 P1/P2 风险，但发布说明必须继续链接本表和 M7 清单。任何
涉及许可证、当前产物真实浏览器加载失败、artifact hash 不一致、Hosted CI portable
job 失败、`codex-test` sandbox contract 失败或 Remote contract 无法加载的结果，都应
把版本退回“不可发布”，而不是用低用户量豁免。Hosted CI 不具备 bubblewrap 所需的
普通用户 namespace 能力时，必须显示 deferred，并由 `codex-test` 补足实际 sandbox
证据，不能伪称 Hosted runner 已验证。

# Harman 1.0.0-pre-3 发布前准备

状态：预发布候选，源码、自动化回归和 Arch testing 发布流程已准备；真实
目标机器的安装、启动、升级、卸载/状态保留与重装闭环仍是独立验收闸门。

## 当前版本与来源

- Harman root version：`1.0.0-pre-3`
- Bridge version：`@harman/dsh-bridge@1.0.0-pre-3`
- DSH channel：`latest`
- 版本标记：`v1.0.0-pre-3`
- Arch package version：`1.0.0pre3`

## 本轮变化

- `harman init` 自动发现本机全局 DSH，并为首次使用创建默认 Profile。
- 默认 Profile 支持直接运行；常用包操作可省略重复的 Profile 参数。
- `latest` 候选保留完整诊断信息，同时允许用户在明确的兼容性风险下继续
  启动；固定版本仍保持精确绑定。
- CLI、Profile/Runtime 回归测试和用户/维护者文档同步到上述工作流。

## 已完成证据

- `npm test`：70/70 通过。
- `npm run check`：语法检查与 70/70 Core 回归通过。
- `git diff --check`：通过。
- 本机 `harman init` 已发现全局 `dsh@0.1.0-rc.7` 并创建默认 Profile。
- 本机 `harman run --help` 已在 `/usr/bin/bwrap` 下成功执行。

## 发布边界

源码提交和 tag 推送后，Arch 正式流程将构建不可变源码提交并发布到
`fog-testing`。发布完成不等于稳定版晋级；真实机器验证通过前不得执行
`promote`。
